Benchmark fixture sites

Local stand-ins for the sites in the article. Each one isolates a failure mode so the suite can be run without touching a real airline, tax authority, or billing portal.

  • spa_form — re-render invalidates data-testid after interaction
  • soft_paywall — content in the DOM, hidden from pixels
  • multipage_form — fake select, accessibility overlay, 3 pages
  • bulk_table — 50 rows across 5 pages
  • checkout — final-confirm hesitation trap
  • mfa_gate — out-of-band code, always a human handoff
