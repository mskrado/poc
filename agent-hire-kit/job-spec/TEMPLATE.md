# Agent Job Spec (one page)

Fill this in before an agent takes over work a person did. If a line stays blank, the agent isn't ready to start.

1. **Role name:** what you'd call this job if a person held it.
2. **The task:** one sentence. What "done" looks like.
3. **Inputs:** where its work comes from (queue, inbox, repo, sheet).
4. **May touch:** systems, data and actions it is allowed.
5. **Must never touch:** money, customer data, deletes, outbound messages, anything else off-limits.
6. **Stop and hand off when:** the conditions that end a run and send it to a person.
7. **Checker:** the named person who reviews its work.
8. **Check rhythm:** how often, and how many items they can really read in that time.
9. **Escalation path:** who gets it when the checker is out.
10. **Cost line:** run cost per month, and hours of human review per week. Measured, not guessed.
11. **Review date:** when you decide to keep it, change it or switch it off.

Sections in this kit: payback (Av), readiness checklist (Orion), buyout worksheet (Noah), contention test (Rex).
